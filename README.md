# Cummings Consulting Group

A static two-page website for Cummings Consulting Group (energy & sustainability).

- `index.html`: hero graphic, leadership (Larry Cummings), and partners
- `larry-cummings.html`: Larry's bio
- `styles.css`: shared styles, with automatic light and dark mode
- `hero.js`: the animated data center aisle behind the headline (about 4 KB, pauses when off-screen, a still frame for reduced motion)

To use real video footage instead, see the commented `<video>` block in `index.html`. Keep the file under about 3 MB.

It has no build step, no frameworks, no web fonts, and no third-party requests. Open `index.html` in a browser, or host the folder on GitHub Pages, Netlify, or Vercel.
