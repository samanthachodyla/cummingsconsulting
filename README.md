# Cummings Consulting Group

A static two-page website for Cummings Consulting Group (energy & sustainability).

- `index.html`: hero graphic, leadership (Larry Cummings), and partners
- `larry-cummings.html`: Larry's bio
- `styles.css`: shared styles, with automatic light and dark mode

It has no build step, no JavaScript, no web fonts, and no third-party requests. Open `index.html` in a browser, or host the folder on GitHub Pages, Netlify, or Vercel.
